# 游戏匹配服务器（Game Match Server）

一个基于 Linux C++ 的轻量级游戏匹配服务器，支持多客户端并发连接、JSON 协议解析、分数相近配对和超时处理。

## 功能特性

- 基于 epoll 的高并发网络模型，单线程管理上千连接
- JSON 协议通信，支持 `match` 命令和分数匹配
- 分数相近（差值 ≤ 200）的玩家自动配对
- 30 秒超时机制，未匹配时返回失败通知
- 客户端断开时自动从队列中移除

## 快速开始

### 环境要求

- Linux（或 WSL 2）
- g++ 支持 C++11

### 编译

bash
g++ -std=c++11 -o match_server match_server.cpp
